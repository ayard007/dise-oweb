Contenido del Tema

Fundamentos de CSS, del estilo a la animacion

CSS es el lenguaje que controla la presentacion visual de los documentos HTML. Trabaja mediante reglas: cada regla selecciona uno o mas elementos y les aplica un conjunto de propiedades con sus valores.

anatomia-regla.css
/* selector { propiedad: valor; } */
h1 {
  color: #1e2c6e;
  font-size: 32px;
  text-align: center;
}

2.1 Vinculacion con HTML

Existen tres formas de aplicar CSS a un documento HTML, cada una con su uso recomendado:

MetodoComo se aplicaCuando usarlo
En linea (inline)Atributo style en la etiquetaAjustes puntuales; no recomendado a gran escala
Interno (embebido)Etiqueta <style> dentro del <head>Paginas unicas o pruebas rapidas
Externo (vinculado)Archivo .css enlazado con <link>Practica profesional recomendada
vinculacion.html
<!-- Metodo externo (recomendado): en el head -->
<link rel="stylesheet" href="estilos.css">

<!-- Metodo interno: en el head -->
<style>
  body { background-color: #f4f6fb; }
</style>

<!-- Metodo en linea: en la etiqueta -->
<p style="color: red;">Texto rojo</p>

2.2 Propiedades de objetos

Cada elemento HTML es una caja rectangular a la que CSS puede aplicar multiples propiedades. Las mas relevantes se agrupan en familias.

FamiliaPropiedades clave
Texto y tipografiacolor, font-family, font-size, font-weight, line-height, text-align
Modelo de cajawidth, height, padding, margin, border
Fondobackground-color, background-image, background-size
Visualborder-radius, box-shadow, opacity

2.3 Orden de la estructura (selectores y cascada)

CSS decide que estilo aplicar segun la especificidad del selector y el orden en que aparecen las reglas (de ahi "en cascada"). Los selectores fundamentales son:

  • Selector de etiqueta: p { } afecta a todos los parrafos.
  • Selector de clase: .destacado { } afecta a los elementos con class="destacado". Reutilizable.
  • Selector de id: #menu { } afecta al elemento con id="menu". Unico por pagina.
ⓘ
Regla de especificidad: un id pesa mas que una clase, y una clase pesa mas que una etiqueta. Ante igual especificidad, gana la ultima regla declarada.

2.4 Responsivo

El diseno responsivo permite que un sitio se adapte a cualquier tamano de pantalla (movil, tableta, escritorio). Se logra con unidades flexibles y con media queries, que aplican estilos condicionales segun el ancho del dispositivo.

responsivo.css
/* Estilos base para todos los dispositivos */
.contenedor { width: 100%; padding: 40px; }

/* Cuando la pantalla mide 600px o menos */
@media (max-width: 600px) {
  .contenedor { padding: 16px; }
  h1 { font-size: 24px; }
}

2.5 Interactividad

CSS ofrece pseudo-clases que responden a la interaccion del usuario sin necesidad de JavaScript. La mas comun es :hover, que aplica estilos al pasar el cursor. Otras son :focus (al enfocar un campo) y :active (al hacer clic). La propiedad transition suaviza estos cambios.

interactividad.css
.boton {
  background-color: #1e2c6e;
  color: white;
  transition: background-color 0.3s ease;
}
.boton:hover {
  background-color: #7c3aed;
}
Vista previa — pasa el cursor sobre el boton

2.6 Animacion de objetos

Ademas de las transiciones, CSS permite crear animaciones complejas con la regla @keyframes, que define estados intermedios de una animacion, y la propiedad animation, que la aplica a un elemento.

animacion.css
@keyframes deslizar {
  from { transform: translateX(-100px); opacity: 0; }
  to   { transform: translateX(0); opacity: 1; }
}
.tarjeta {
  animation: deslizar 0.8s ease-out;
}

2.7 Lineas de tiempo (control temporal de animaciones)

Una linea de tiempo define en que momento y con que ritmo ocurren los cambios de una animacion. Se controla con estas propiedades:

PropiedadFuncion
animation-durationCuanto dura la animacion (ej. 2s)
animation-delayCuanto espera antes de iniciar
animation-timing-functionEl ritmo: ease, linear, ease-in-out
animation-iteration-countCuantas veces se repite (infinite para siempre)
Porcentajes en @keyframesDefinen fotogramas intermedios (0%, 50%, 100%)

Al encadenar multiples fotogramas con porcentajes y coordinar retrasos entre varios elementos, se construye una linea de tiempo visual completa, base de las interfaces animadas modernas.

Guia de Actividad Guiada para Analizar

Construye y comprende una animacion con linea de tiempo

Esta guia te lleva a construir, paso a paso, un elemento animado que aparece en escena. El objetivo no es solo copiar, sino analizar por que funciona cada linea.

animacion-guiada.html
<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <style>
    .caja {
      width: 150px; height: 150px;
      background-color: #7c3aed;
      border-radius: 12px;
      animation: entrada 1.2s ease-out;
    }
    @keyframes entrada {
      0%   { transform: scale(0) rotate(-90deg); opacity: 0; }
      60%  { transform: scale(1.1) rotate(10deg); }
      100% { transform: scale(1) rotate(0); opacity: 1; }
    }
  </style>
</head>
<body>
  <div class="caja"></div>
</body>
</html>

Preguntas de analisis (responde mientras construyes)

  1. Que ocurre visualmente en el fotograma 0%? Por que el elemento no se ve al inicio?
  2. Que efecto produce que el 60% tenga scale(1.1)? Que sensacion transmite ese "rebote"?
  3. Que pasaria si cambiaras ease-out por linear? Pruebalo y describe la diferencia.
  4. Como modificarias el codigo para que la animacion se repita tres veces?
ⓘ
Modifica los valores y vuelve a cargar el navegador tras cada cambio. La experimentacion es parte esencial del aprendizaje: observa, ajusta y concluye.

Contenido del Tema

Fundamentos de JavaScript y jQuery

JavaScript es el lenguaje de programacion que se ejecuta en el navegador y permite dotar de comportamiento e interactividad a las paginas web. Es la tercera capa del desarrollo de front-end, junto a HTML (estructura) y CSS (presentacion).

3.1 Vinculacion con HTML

Al igual que CSS, JavaScript se puede incluir de forma interna o externa. La practica recomendada es un archivo .js externo, enlazado con la etiqueta <script>, colocada justo antes de cerrar el </body> para que el HTML cargue primero.

vinculacion-js.html
<!-- Externo (recomendado): antes de cerrar body -->
  <script src="script.js"></script>
</body>

<!-- Interno -->
<script>
  alert("Hola desde JavaScript");
</script>

3.2 La sintaxis de JavaScript

La sintaxis define las reglas para escribir codigo valido. Los elementos fundamentales son:

ElementoDescripcionEjemplo
VariablesAlmacenan datos. Se declaran con let, const o varlet nombre = "Ana";
Tipos de datoTexto (string), numero, booleano, arreglo, objetolet edad = 20;
OperadoresRealizan operaciones aritmeticas o logicas+ - * / === &&
CondicionalesEjecutan codigo segun una condicionif (edad >= 18) { }
ComentariosNotas que no se ejecutan// esto es un comentario
sintaxis.js
// Declaracion de variables
let nombre = "Estudiante";
const anio = 2025;

// Condicional
if (anio === 2025) {
  console.log("Bienvenido, " + nombre);
} else {
  console.log("Otro anio");
}

3.3 Eventos

Un evento es una accion del usuario o del navegador que JavaScript puede detectar y responder: un clic, mover el cursor, escribir en un campo, cargar la pagina. Se escuchan con addEventListener o con atributos como onclick.

EventoSe dispara cuando
clickEl usuario hace clic en un elemento
mouseoverEl cursor entra sobre un elemento
keydownSe presiona una tecla
submitSe envia un formulario
loadLa pagina termina de cargar
eventos.js
const boton = document.getElementById("miBoton");

boton.addEventListener("click", function() {
  alert("Hiciste clic en el boton");
});

3.4 Creacion de funciones

Una funcion es un bloque de codigo reutilizable que ejecuta una tarea. Se define una vez y se puede llamar (invocar) tantas veces como se necesite, opcionalmente recibiendo datos (parametros) y devolviendo un resultado.

funciones.js
// Definicion de la funcion con un parametro
function saludar(nombre) {
  return "Hola, " + nombre + ". Bienvenido al sitio.";
}

// Invocacion de la funcion
let mensaje = saludar("Maria");
console.log(mensaje);

3.5 El framework jQuery

jQuery es una libreria de JavaScript que simplifica tareas comunes como seleccionar elementos, manejar eventos y crear animaciones, con una sintaxis mas corta. Aunque JavaScript moderno ha reducido su necesidad, sigue siendo util conocerla por su presencia en numerosos proyectos.

jquery.html
<!-- Vincular jQuery desde un CDN -->
<script src="https://code.jquery.com/jquery-3.7.1.min.js"></script>

<script>
  // JavaScript puro:
  // document.getElementById("titulo").style.color = "red";

  // Equivalente en jQuery (mas corto):
  $("#titulo").css("color", "red");

  // Evento clic con jQuery
  $("#miBoton").click(function() {
    $("#mensaje").slideToggle();
  });
</script>
⚠
jQuery requiere vincularse antes de usarlo. El simbolo $ es el punto de entrada de la libreria: representa la funcion principal de jQuery para seleccionar elementos.

Guia de Actividad Guiada para Analizar

Un cambio de tema (claro/oscuro) con JavaScript

Construiras un boton que alterna entre modo claro y oscuro. Analiza como se combinan evento, funcion y manipulacion de clases.

tema-guiado.html
<style>
  body { background: white; color: #16182b; transition: 0.3s; }
  body.oscuro { background: #16182b; color: white; }
</style>

<button id="cambiar">Cambiar tema</button>

<script>
  const boton = document.getElementById("cambiar");

  function alternarTema() {
    document.body.classList.toggle("oscuro");
  }

  boton.addEventListener("click", alternarTema);
</script>

Preguntas de analisis

  1. Que hace el metodo classList.toggle("oscuro")? Que ocurre si la clase ya esta puesta?
  2. Por que la funcion alternarTema se pasa sin parentesis al addEventListener?
  3. Que papel cumple la propiedad transition del CSS en esta interaccion?
  4. Como agregarias un segundo boton que solo active el modo oscuro, sin alternar?

Pregunta de Conocimiento Previo

Activa lo que ya sabes
●
Hasta ahora tus sitios funcionan abriendo un archivo en tu propia computadora. Reflexiona: como es posible que millones de personas puedan ver un mismo sitio web escribiendo una direccion como "www.ejemplo.com"? Donde vive realmente un sitio web cuando esta "en internet" y no en tu equipo?
Un sitio web publicado vive en un servidor: una computadora encendida permanentemente y conectada a internet (el hosting o alojamiento). Para que las personas lo encuentren sin memorizar numeros, se le asigna un nombre facil de recordar (el dominio), que un sistema global traduce a la direccion del servidor. Publicar consiste en copiar tus archivos a ese servidor.

4.1 Dominio y hosting

Publicar un sitio web requiere dos componentes complementarios:

4.2 Administracion

Publicar no es el final: administrar el sitio implica mantenerlo, actualizarlo y controlar sus versiones. Las tareas fundamentales de administracion son:

  • Control de versiones: registrar los cambios del sitio con Git, de modo que se pueda volver a una version anterior si algo falla.
  • Actualizacion de archivos: subir nuevas versiones de los archivos al servidor cuando el sitio cambia.
  • Gestion del repositorio: organizar los archivos, escribir descripciones claras de cada cambio (commits) y mantener el proyecto ordenado.
  • Verificacion: comprobar que el sitio publicado funcione correctamente en distintos navegadores y dispositivos.
ⓘ
GitHub reune hosting y administracion en un solo lugar: el repositorio guarda y versiona tus archivos, y GitHub Pages los publica. Por eso es la plataforma elegida para tu proyecto integrador.

Actividad 2 · Practica de Aprendizaje Significativo

Publica tu primer sitio en linea

Publicaras un sitio web sencillo en internet mediante GitHub Pages y obtendras una URL real y compartible. Es la culminacion practica de todo el proceso.

Instrucciones paso a paso

1
Crea una cuenta en GitHub

Ingresa a github.com y registrate con tu correo institucional o personal.

2
Crea un repositorio publico

Presiona "New repository", asignale un nombre (por ejemplo mi-sitio) y marcalo como publico.

3
Sube tus archivos

Usa "Add file > Upload files" y sube tu index.html junto con el CSS y el JS. El archivo principal debe llamarse index.html.

4
Activa GitHub Pages

Ve a Settings > Pages, selecciona la rama principal como fuente y guarda.

5
Verifica tu URL publica

GitHub generara una direccion del tipo tuusuario.github.io/mi-sitio. Abrela desde otro dispositivo para confirmar que funciona.

✓
Criterio de logro: el sitio debe ser accesible desde la URL publica en cualquier navegador, sin depender de tu computadora.

Guia de Actividad Guiada para Analizar

Analiza el ciclo de una actualizacion

Una vez publicado, actualizaras tu sitio y observaras como se refleja el cambio en linea. Analiza cada fase del ciclo de administracion.

1
Modifica un archivo

En tu repositorio, edita el index.html (por ejemplo, cambia el titulo principal) usando el editor de GitHub.

2
Registra el cambio (commit)

Escribe una descripcion clara del cambio, por ejemplo "Actualizacion del titulo de portada", y confirma.

3
Espera la republicacion

GitHub Pages vuelve a publicar automaticamente. Recarga tu URL publica tras uno o dos minutos.

Preguntas de analisis

  1. Que ventaja tiene que cada cambio quede registrado como un commit con descripcion?
  2. Por que es una buena practica escribir descripciones de commit claras y especificas?
  3. Que pasaria si cometieras un error: como te ayudaria el control de versiones a recuperar una version anterior?
  4. Que diferencia hay entre editar el archivo en tu computadora y editarlo directamente en el repositorio?
