Fundamentos de HTML

El esqueleto de la web para mentes visuales.

¿Qué es HTML?

HTML (HyperText Markup Language) no es un lenguaje de programación matemático; es un lenguaje de marcado. Como diseñador, piénsalo como estructurar un documento en InDesign: defines qué es un título, qué es un párrafo, dónde va una imagen y cómo se relacionan entre sí.

Problema Base

Imagina que tienes un lienzo en blanco (el navegador). Tienes el texto de una noticia y una foto. Si solo los "arrojas" al lienzo, el navegador no sabe qué hacer. ¿Cómo le explicamos al navegador qué parte es el título principal y cuál es la foto?

Anatomía de una Etiqueta

Para hablar con el navegador usamos etiquetas (tags). Casi todas funcionan como "contenedores" que envuelven el contenido.

<h1>

Apertura

Hola Mundo

Contenido

</h1>

El Esqueleto del Documento

Todo archivo `.html` necesita una estructura básica. Es como el marco de un cuadro; sin él, el contenido se cae.

  • <!DOCTYPE html>

    Avisa que usamos HTML5 moderno.

  • <html>

    La raíz que envuelve todo.

  • <head>

    El "cerebro". Configuraciones invisibles, como el título de la pestaña.

  • <body>

    El lienzo. Todo lo visual va aquí.

<!DOCTYPE html>
<html lang="es">

  <head>
    <meta charset="UTF-8">
    <title>Mi Primer Lienzo</title>
  </head>

  <body>
    <!-- Lo que se ve en pantalla va aquí -->
  </body>

</html>

Práctica Activa:

Copia el código de arriba, pégalo en un Bloc de Notas, guárdalo como index.html (asegúrate de que en 'Tipo' diga 'Todos los archivos') y ábrelo dándole doble clic. Verás una página en blanco, ¡pero la pestaña tendrá tu título!

Pintando el Lienzo: Textos e Imágenes

Ahora que tenemos el <body>, vamos a ponerle contenido. Piensa en estas etiquetas como tus herramientas de texto y marco de imagen en tu software de diseño.

Jerarquía Tipográfica

Usamos de <h1> (más importante) a <h6> (menos importante) para títulos, y <p> para párrafos.

<h1>Título Principal</h1>
<h2>Subtítulo de Sección</h2>
<p>Este es un párrafo de texto normal que explica el tema de la sección con más detalle.</p>

Resultado Visual

Título Principal

Subtítulo de Sección

Este es un párrafo de texto normal que explica el tema de la sección con más detalle.

Imágenes y Enlaces

La etiqueta <img> no tiene cierre, usa el atributo src (source) para la ruta. Los enlaces usan <a> (anchor) y el atributo href.

<!-- Imagen (Nota el atributo 'alt' para accesibilidad) -->
<img src="foto.jpg" alt="Descripción visual">

<!-- Enlace -->
<a href="https://une.edu.mx">Visita la UNE</a>

Organizando Datos: Viñetas y Cuadrículas

Como diseñadores, a menudo necesitamos organizar información que no es solo texto corrido. Para listas de herramientas o cuadrículas de precios, usamos etiquetas específicas.

Viñetas (Listas)

Usamos <ul> para listas desordenadas (puntos) y <ol> para listas ordenadas (números). Cada elemento de la lista va dentro de un <li>.

<ul>
  <li>Photoshop</li>
  <li>Illustrator</li>
</ul>
  • Photoshop
  • Illustrator

Tablas (Cuadrículas)

Las tablas son perfectas para alinear datos. Usamos:
<table>: El contenedor principal.
<tr>: Table Row (Fila).
<th>: Table Header (Celda de encabezado).
<td>: Table Data (Celda de datos normal). 

<table border="1">
  <tr>
    <th>Servicio</th>
    <th>Costo</th>
  </tr>
  <tr>
    <td>Logotipo</td>
    <td>$5,000</td>
  </tr>
</table>

Logotipo $5,000

Diseño en línea: Color y Tipografía

Aunque el diseño profundo se hace con CSS (lo veremos más adelante), podemos aplicar diseño rápido y directo a nuestras etiquetas HTML usando el atributo style. Esto se llama "Estilos en línea".

La Sintaxis del Estilo

<etiqueta style="propiedad: valor;">

Color de Fondo (Color de Hoja)

Para pintar todo el lienzo, aplicamos el estilo al <body> usando background-color.

<body style="background-color: lightblue;">
Esta "hoja" ahora es azul claro.

Tipo de Texto y Color

Podemos cambiar la tipografía con font-family y el color con color. ¡Se pueden combinar separándolos por punto y coma (;) !

<h1 style="font-family: Arial; color: red;">
  Impacto Visual
</h1>

Reto Final: El Menú de la Cafetería

Es hora de poner a prueba tus conocimientos. Este ejercicio lo realizarás fuera de esta guía, en tu propio entorno, para demostrar que dominas la creación de un archivo HTML desde cero integrando estructura, diseño, listas y tablas.

Requisitos del Proyecto:

  1. Prepara tu entorno: Abre el Bloc de notas o VS Code. Guarda un archivo nuevo como menu-cafe.html.
  2. Estructura Base: Crea el esqueleto (<!DOCTYPE html>, html, head, body).
  3. Estilo del Fondo: Aplica un estilo al <body> para que el fondo (background-color) sea #fffbeb (un tono crema suave).
  4. Tipografía Global: Haz que todo el texto use font-family: Arial.
  5. Encabezado: Añade un título <h1> centrado e inserta una imagen (puede ser un placeholder) que simule el logo de la cafetería.
  6. La Tabla de Precios: Crea una <table> con bordes. Debe tener dos columnas ("Bebida" y "Precio") y al menos tres filas con opciones de café.
  7. Los Ingredientes (Viñetas): Debajo de la tabla, añade un título <h3> ("Adicionales") y usa una lista desordenada (<ul>) para listar ingredientes extras (leche de avena, caramelo, etc.).

¿Te atascaste? Aquí tienes un empujón:

Solo despliega este código si necesitas revisar cómo empezar la estructura o cómo unir los estilos en el body.

Ver estructura sugerida de inicio 
<!DOCTYPE html>
<html>
<head>
    <title>Menú Café UNE</title>
</head>
<!-- Observa cómo se aplica fondo y tipografía al mismo tiempo -->
<body style="background-color: #fffbeb; font-family: Arial;">

    <!-- Aquí va tu H1, Tabla e Imagen -->

</body>
</html>
